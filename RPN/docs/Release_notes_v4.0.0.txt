Release Notes for Version 4.0.0
===============================

Overview
--------

Version 4.0.0 introduces a first-class geometry and transformation layer.

RPN can now create immutable 2D and 3D transforms, compose them in execution
order, apply them to points, invert them, and inspect their homogeneous matrix
representation.


Architecture
------------

The new `RPN::Transform` domain object owns:

* transformation dimension
* homogeneous matrix representation
* point application
* composition order
* inversion

2D transforms use 3x3 homogeneous matrices. 3D transforms use 4x4 homogeneous
matrices.

Transform objects are distinct from general matrices so programs can express
geometric intent while reusing the established matrix implementation.

Shared Inspection
-----------------

    transformmatrix

This command replaces a transform with a copy of its homogeneous matrix.


Composition Order
-----------------

Composition follows execution order:

    FIRST SECOND compose2d
    FIRST SECOND compose3d

The resulting transform applies FIRST and then SECOND.

This user-facing rule is intentionally explicit because the underlying matrix
product is formed in the opposite textual order for column vectors.


Angles
------

All rotation commands honor the existing angle mode:

    degrees
    radians


Coordinate Geometry
-------------------

`point2d` and `point3d` create points represented by existing vector objects.

`distance2d` and `distance3d` compute Euclidean distance between compatible
points.

This preserves interoperability with vector mathematics without introducing a
duplicate point-storage object.

Compatibility
-------------

Version 4.0.0 adds new commands and objects without changing existing vector or
matrix semantics.
