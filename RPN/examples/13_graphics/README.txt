13 Graphics
===========

SVG-first graphics recipes for RPN 4.1.

* Basic SVG Scene: Draws and saves styled primitive shapes.
* Transformed Shapes: Reuses 2D transformations with graphics.
* Data Plot: Plots paired vectors.
* Function Plot: Samples an executable RPN function.
* SVG QR Code: Creates a scalable QR code when Text::QRCode is installed.
